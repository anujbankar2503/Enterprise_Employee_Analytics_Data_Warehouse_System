# Support

## Getting Help

For setup and usage questions:

1. Read [README.md](README.md).
2. Search existing GitHub issues.
3. Open a new issue with the `question` label if the answer is not already documented.

Repository:

<https://github.com/anujbankar2503/Enterprise_Employee_Analytics_Data_Warehouse_System>

## Include in a Support Request

Please include:

- Operating system and Python version.
- MySQL version and Streamlit version.
- The command you ran.
- The complete error message, excluding passwords and private data.
- Whether the issue affects the UI, database setup, ETL, or analytics.

Do not include `app/.env`, credentials, private employee records, or database
exports in an issue.

## Bug Reports and Security Issues

Use a bug report for reproducible product problems. Use the private process in
[SECURITY.md](SECURITY.md) for vulnerabilities or exposed credentials.
